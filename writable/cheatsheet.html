Comandos PM2 (Como www-data)

Sempre que precisar interagir com o PM2, use o usuário www-data. Se rodar como root, você pode causar problemas de permissão.

  • $sudo -u www-data pm2 list
    Lista todas as aplicações rodando.
  • $sudo -u www-data pm2 logs
    Mostra os logs de erro e saída.
  • $sudo -u www-data pm2 monit
    Abre o painel de monitoramento de CPU e Memória.
  • $sudo -u www-data pm2 restart [id/nome]
    Reinicia um app específico.

Permissões de Arquivos

O servidor web usa o usuário www-data. Se você logar via SSH como root e rodar comandos como git pull, os novos arquivos pertencerão ao root, bloqueando o deploy automático.

Solução: Use o botão "Resetar Permissões" neste painel caso o deploy trave com erro de "Operation not permitted".
